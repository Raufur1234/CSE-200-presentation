% ------------------------------------------------------------------ ONE ROTATION
%  The whole idea in one frame: pin a node, turn the tree about it.
%
%  Layout rule for this frame: a node's x is its position in sorted order and
%  NEVER changes; only its depth does. A rotation therefore moves nodes
%  straight up or straight down, which is what makes the ghosts readable --
%  every faded circle sits directly above or below where its node landed. It
%  also makes the payoff visible rather than asserted: nothing moves sideways,
%  so the search order cannot break.

  broken. Then you turn the whole tree clockwise about that pin, the way you
  would turn a stiff wire. 20 ends up on top, 30 ends up on the right. Point at
  the faded circles: that is where each node was a second ago. Then point at
  the ruler: nothing slid left or right. That is why a rotation can never break
  the search rule, and it only ever re-links three pointers, so it is constant
  time.}
\end{frame}

% ------------------------------------------------------------------ rotation power
\begin{frame}[label=p2]{The beauty: one constant operation fixes everything}
  \vspace{-0.2em}
  \begin{center}
  {\large\bfseries\color{avlptwo}What makes a rotation elegant}
  \end{center}

  \vspace{0.35em}
  \begin{center}
  \begin{minipage}{0.78\textwidth}
  \begin{itemize}
    \setlength{\itemsep}{0.45em}
    \item {\color{avlfib}\bfseries Only three links change}\\
      {\color{avlmuted}\small $O(1)$ no matter the tree size}
    \item {\color{avlfib}\bfseries Restores subtree height}\\
      {\color{avlmuted}\small Parent sees no change, repair stops}
    \item {\color{avlfib}\bfseries Search order is safe}\\
      {\color{avlmuted}\small Left-right order never breaks}
    \item {\color{avlfib}\bfseries One rotation suffices}\\
      {\color{avlmuted}\small No need to check nodes above}
  \end{itemize}
  \end{minipage}
  \end{center}

  \vspace{0.4em}
  \begin{center}
    {\footnotesize\color{avlmuted}A rotation changes only three pointers ---
     no recursion, no loops. That is why it}\\[0.15em]
    {\normalsize\bfseries\color{avlfib}runs in constant time.}\\[0.35em]
    {\normalsize\color{avlfib}Four cases. \quad One pattern. \quad Perfect balance.}
  \end{center}

  \note{The heart of AVL. A rotation is O(1): only three pointers move. It
  restores the subtree to its original height, so the parent tree sees nothing
  has changed. That is why one rotation is always enough for insertion. This is
  the elegant core that makes AVL practical.}
\end{frame}

  \note{Here is the payoff. Insertion in an AVL tree is logarithmic: walk down
  log n steps to the leaf, then walk back up log n steps, rotating at most once.
  Total: O(log n). Without rebalancing, a sorted insertion into a normal BST is
  linear: a million keys takes a million comparisons. With AVL, it takes 20.
  That is fifty thousand times faster. For a few pointers, you get guaranteed
  logarithmic time no matter what keys arrive and in what order.}
